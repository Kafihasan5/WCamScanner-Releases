# CamDocScanner releases

Signed Android builds of CamDocScanner (WCamScanner). Download the latest APK from [Releases](https://github.com/Kafihasan5/WCamScanner-Releases/releases/latest).

- `WCamScanner-<version>-arm64.apk`: most phones (64-bit ARM)
- `WCamScanner-<version>-universal.apk`: every device

The app checks this page for updates and installs them over the old version; your documents stay.
